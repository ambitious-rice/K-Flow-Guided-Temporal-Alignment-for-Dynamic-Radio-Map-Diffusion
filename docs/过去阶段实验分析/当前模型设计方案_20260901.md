# 当前模型设计方案

更新时间：2026-09-01。本文件只描述当前已经训练、评测或作为基线保存的方案；不把待做的结构、损失或训练计划写成既有设计。

## 1. 任务与共同输入输出

目标是由动态场景条件和稀疏 RSS 观测补全一张归一化到 `[0, 1]` 的 `128 × 128` Radio Map。当前主要实验采用 no-Tx 设定，即不把显式 Tx heatmap 当作条件输入。

一帧输入包含：

- 静态 building mask；
- 动态 vehicle / traffic 条件；
- 稀疏采样 mask `m`；
- 仅在 `m=1` 处非零的观测图 `observed_rss`。

模型输出为完整干净图预测 `x_hat`。评测除整图指标外，还报告未观测自由空间指标，避免由已知观测点掩盖补全区域的真实误差。

## 2. 当前主线：no-Tx x0 HVDiT

主线模型是条件扩散 Transformer，采样器从高斯噪声开始，以场景条件和稀疏 RSS 作为条件，在每一步预测干净图 `x0`，而不是预测 epsilon。

```text
(building, vehicle, sampling_mask, observed_rss)
                  │
                  ▼
            条件编码 / condition cache
                  │
x_t + diffusion timestep ──► HVDiT denoise ──► x0 或等价采样更新
                  │
                  ▼
              DDIM 最终预测 x_hat
```

扩散公共设置为 1,000 个线性 beta timestep，`prediction_type: sample`（x0），默认 DDIM-20。历史 Stage-A 单帧对照和本次观测敏感度实验均使用这一采样定义。

### 2.1 单帧原 DiT

原 DiT 每次仅从当前帧条件生成一张图。它是后续对齐损失和 W16 联合模型的初始化/对照来源。

- checkpoint：`runs/rmdm_hvdit_v4_x0_no_tx_continue/t1_from10k_to50k/checkpoints/best.pth`；
- 训练目标：x0 重建、校准与物理相关损失；
- 推理：无观测硬覆盖，稀疏观测只通过条件编码影响预测；
- 用途：单帧基线、带噪观测引导对照、W16 的初始化来源。

该模型的机制不能概括为“忽略观测”。本次有限差分测量显示它对单个观测的改变有空间扩散响应；只是这种耦合弱于 alignment DiT。

### 2.2 单帧 DiT 的训练方法与历史配置

单帧训练把每一个视频帧作为一个 `window_size=1` 样本。训练集读取所有帧起点，训练入口对这一版本要求数据集恰为 1,050,000 帧；DataLoader 随机打乱、`drop_last=True`，并在每个 epoch 更新稀疏观测的 `SamplingPolicy`。每个 batch 的 sparse mask 与 `observed_rss` 因而是训练条件，而不是在训练后再额外加到输出上的约束。

一次训练 step 的实际计算为：

```text
x ──► 按扩散 timestep 加噪 ──► x_t

(x_t, timestep, building, vehicle, sampling_mask, observed_rss)
  ──► 单帧 HVDiT ──► (predicted_x0, cal)
```

`cal` 是同形状的辅助物理相关输出。训练目标为：

```text
L_clean = MSE(predicted_x0, x)
L_cal   = MSE(cal, x)

L_spatial = pinn_weight · (L_semantic_anchor + L_equation)

L_total = L_clean + alpha_obs · L_obs + L_cal + L_spatial
```

`L_equation` 与 `L_semantic_anchor` 由 `cal`、building 和 vehicle 构造；no-Tx 配置会将 Tx source supervision 置零。训练代码还会从 `predicted_x0` 反推出 epsilon 并记录其 MSE，但**不会把该 epsilon MSE 加入 `L_total`**。默认空间正则为 PINN，历史配置的 `pinn_k=0.2`、`pinn_weight=1.0`。

`L_obs` 仅用于 alignment 变体：

```text
L_obs = mean_b [ sum_i m_i · (predicted_x0_i - x_i)^2 / max(sum_i m_i, 1) ]
```

因此原 DiT 的 `alpha_obs=0`，alignment DiT 的 `alpha_obs=1.0`。两者都直接监督干净真值 `x`，不会在训练或采样时硬覆盖预测图的观测像素。

优化器为 AdamW，学习率使用线性 warmup 后的余弦退火：

| 项目 | 原 DiT continuation | alignment DiT（from scratch） |
|---|---:|---:|
| 随机种子 | 20260717 | 20260717 |
| GPU 数 | 4 | 8 |
| 每 GPU batch | 32 | 16 |
| 梯度累积 | 2 | 2 |
| 有效全局 batch | 256 | 256 |
| 初始学习率 | 5e-4 | 5e-4 |
| AdamW betas / eps / weight decay | `[0.9, 0.95]` / 1e-8 / 0.01 | 相同 |
| 梯度裁剪 | 1.0 | 1.0 |
| 训练精度 | bf16 | bf16 |
| warmup | 2,000 step | 2,000 step |
| 余弦退火总步数 / 最小学习率 | 50,000 / 5e-5 | 50,000 / 5e-5 |
| 配置的最大 step | 50,000 | 40,000 |
| checkpoint 间隔 | 1,000 step | 1,000 step |

原 DiT 是 continuation run；训练入口要求给出来源 checkpoint，除非显式 `--from-scratch`。alignment DiT 使用 `--from-scratch`，并传入 `--observation-alignment-weight 1.0`。这解释了两者除 `L_obs` 外还存在初始化与训练轨迹差异，不能把所有性能差异严格归因于对齐损失。

验证选择使用 Stage-A 的 `p=1/2/3` 平均整图 NMSE，越小越好，并保存 `best.pth` 和 `last.pth`：

| 项目 | 原 DiT continuation | alignment DiT |
|---|---:|---:|
| 首次验证 | step 15,000 | step 2,000 |
| 验证间隔 | 5,000 step | 2,000 step |
| 可早停的最早 step | 25,000 | 40,000 |
| 连续未改善耐心值 | 2 | 3 |
| 实际被选中的最佳 step | 25,000 | 20,000 |

该配置说明 alignment run 的验证更密集，但它并非严格一因素消融。后续若需回答“仅 `L_obs` 的因果效应”，需要统一初始化、训练预算、数据与验证 schedule；这属于新的训练实验，不是当前历史 checkpoint 已经提供的事实。

### 2.3 alignment DiT

alignment DiT 与原 DiT 使用相同的模型主干、条件定义和 DDIM 采样器。区别在训练期额外加入已观测位置的对齐损失：

```text
L_obs = mean_b [ sum_i m_i · (x_hat_i - x_i)^2 / max(sum_i m_i, 1) ]

L_total = L_clean + 1.0 · L_obs + L_calibration + L_physics
```

这里比较的是预测和干净训练真值，不是在推理时把观测直接写回输出。干净训练数据中两者在可见点相同，所以该损失会强化“可见点应被准确保留”的偏好。

- checkpoint：`runs/rmdm_hvdit_v4_x0_no_tx_continue/t1_obs_alignment_from_scratch_2kval_20260804/checkpoints/best.pth`；
- 最佳验证 step：20,000；
- 参数：`--observation-alignment-weight 1.0`；
- 已知效果：干净稀疏验证显著提升；含噪观测下对噪声感知引导的适应能力下降。

因此，它是一个已验证的训练变体，不是另一套模型结构。

### 2.4 W16 联合时序 DiT

W16 在一次扩散采样中联合预测连续 16 帧。它由单帧 no-Tx x0 DiT 初始化，利用相邻帧共享的静态传播结构和连续动态条件提供额外约束。

已跟踪配置 `configs/hvdit_v4_x0_w16_ratebalanced_no_tx/w16_from_no_tx_w1_4gpu.yaml` 的关键结构为：

| 部件 | 设置 |
|---|---|
| 时间 / 空间 patch | `2 / 4` |
| local / global token dim | `384 / 768` |
| local / global depth | `2 / 11` |
| head dim | `64` |
| local kernel | `[3, 7, 7]` |
| decoder token channels | `192` |
| decoder stage channels | `[128, 64]` |
| 预期可训练参数量 | 1.26--1.40 亿 |

设计上，局部时空 token 用局部注意力聚合邻域信息，global token 用注意力连接更远的位置和帧；随后 decoder 把 token 表示还原为逐帧图像。训练时对 1%--10% 观测率做平衡加权，以避免高观测率样本主导 x0 损失。

已有证据只支持：W16 在当前 no-Tx、固定稀疏观测、DDIM-50 的验证中提高逐帧重建精度，且低观测率收益最大。尚未有单独的时间连续性指标，因此不能把它写成已证明的“视频质量提升”。

## 3. 历史强基线：RMDM-SF 物理双 U-Net

当前比较保留历史 RMDM-SF sparse U-Net。该 checkpoint 内是组合模型，而非两个独立模型：

```text
场景条件与稀疏观测
        │
        ▼
第一阶段 Generic_UNet / hwm 分支：得到物理相关的 cal 表示
        │
        ▼
主 diffusion U-Net：在条件下进行扩散重建
        │
        ▼
完整 Radio Map 预测
```

其历史训练损失由扩散损失、`cal` 重建损失和 `cal` 上的 PINN 物理约束组成。用于当前 no-Tx 对照的 checkpoint 为：

```text
runs/rmdm_sf_sparse_v2_fullimage_obstacle_no_tx_tx_source_20260802/epoch_005.pth
```

这个 U-Net 是必要的强基线。现有 U-Net/DiT 历史记录的训练预算和 manifest 未完全匹配，因而不能把已有差异归结为“Transformer 一定更好”或“卷积一定更好”。

## 4. 采样侧的噪声模块

噪声估计、观测校正和 data assimilation 不改变上述任一主干的结构；它们是在冻结扩散模型之上运行的采样/后处理模块。

### W16 窗口级噪声估计

对一个 16 帧窗口，将观测分为 4 折；每次隐藏一折，用 8 个 DDIM 样本得到被隐藏观测的预测均值 `mu_i` 与模型方差 `v_i`。经干净验证集校准后，基于边缘高斯似然估计观测噪声方差：

```text
sigma² = argmin_s² 1/2 · mean_i[
  log(v_i + s²) + (y_i - mu_i)² / (v_i + s²)
]
```

交叉隐藏防止模型直接看到待评估观测，避免残差被条件输入人为压低。

### 噪声感知 DDIM 引导

采样后段可对预测 `x0` 的观测残差求梯度，并更新当前扩散样本。引导只使用 mask 内观测；给定或估计的观测噪声方差越大，更新越弱，从而避免把噪声硬写入生成图。

该模块与 alignment DiT 的关系要谨慎解释：原 DiT 在注入噪声下能从噪声感知引导获益，而 alignment DiT 几乎没有变化。这是训练偏好与采样引导交互的现象，不意味着采样模块改变了模型结构。

## 5. 当前实验位置与边界

| 角色 | 当前实际模型 / artifact | 可以作出的表述 |
|---|---|---|
| 单帧生成对照 | 原 no-Tx x0 DiT | 已有可复现的单帧扩散基线 |
| 干净稀疏性能候选 | alignment DiT | 对齐训练显著改善当前干净验证，但带噪稳健性有边界 |
| 时序主线 | W16 rate-balanced DiT | 联合 16 帧提高当前逐帧重建，时间连续性尚待专门指标 |
| 卷积基线 | RMDM-SF 物理双 U-Net | 必须保留的强基线，尚无严格公平的架构消融 |
| 高噪声处理 | W16 噪声估计 + 噪声感知 DDIM 引导 | 采样侧方法，不是新网络主干 |

本次观测敏感度结果进一步说明：alignment DiT 对观测点自身和未观测区域的有限差分响应都高于原 DiT；该结果不支持把 DiT 的问题概括为“测量信息无法传播到场”。详见 `观测敏感度有限差分分析_20260901.md`。
