# W1 观测平衡训练修正版 v1

该版本独立于已有 W1 训练代码，原来的 `rmdm_hvdit_v4_x0` 和
`rmdm_hvdit_v4_x0_continue` 不需要修改。

## 文件位置

训练配置：

```text
configs/hvdit_v4_x0_observation_balance/w1_v1.yaml
```

训练实现：

```text
src/rmdm_hvdit_v4_x0_observation_balance/
scripts/train_w1_observation_balance_segment.py
scripts/run_w1_observation_balance_training.py
```

## 训练内容

- 从原始 W1 最佳 checkpoint 加载模型参数；
- optimizer 和学习率从修正版 step 0 重新开始；
- 训练采样率保持 1%--10% 均匀分布；
- 观测噪声使用 `0/0.01/0.03/0.05` 和 `50%/20%/15%/15%`；
- 从输入点之外选择相当于输入点数量 25% 的留出点；
- 留出点不进入模型，只计算权重 0.10 的 clean-target loss；
- 10% 样本清空观测输入，场景条件和训练 target 保持不变；
- 观测点 loss 权重先升至 0.25，4k 后逐步降至 0.05；
- 最多训练 12k step，每 1k step 结束一个训练段并执行固定测试。

## 运行前准备

控制脚本会读取基线汇总：

```text
runs/observation_balance_validation/original_w1/summary.json
```

该汇总需要包含 `fast_w1`、`full_w1` 和 `w1_da_gate`。如果还没有生成，先运行：

```bash
python scripts/run_observation_balance_validation.py prepare \
  --suite configs/evaluation/observation_balance_validation_v1.yaml \
  --variant w1 \
  --candidate-id original_w1 \
  --config configs/hvdit_v4_x0_no_tx_continue/t1_obs_alignment_from_best25k_8gpu.yaml \
  --checkpoint runs/rmdm_hvdit_v4_x0_no_tx_continue/t1_from10k_to50k/checkpoints/best.pth \
  --manifest manifests/dynamic_sparse_v2_semantic_vehicle/val_subset_v1.json \
  --output-root runs/observation_balance_validation \
  --stages fast_w1,full_w1,w1_da_gate

python scripts/run_observation_balance_validation.py run \
  --candidate-id original_w1 \
  --output-root runs/observation_balance_validation \
  --gpus 0,1,2,3,4,5,6,7 \
  --python /data/fzj/conda_envs/RMDM_HVDIT_V2/bin/python

python scripts/run_observation_balance_validation.py summarize \
  --candidate-id original_w1 \
  --output-root runs/observation_balance_validation
```

## 启动训练

```bash
/data/fzj/conda_envs/RMDM_HVDIT_V2/bin/python \
  scripts/run_w1_observation_balance_training.py \
  --config configs/hvdit_v4_x0_observation_balance/w1_v1.yaml
```

控制脚本依次执行：

```text
训练 1000 step → fast_w1 → 判断 → 继续训练或运行 full_w1 + w1_da_gate
```

再次执行相同命令时，会读取：

```text
runs/rmdm_hvdit_v4_x0_observation_balance/w1_v1/controller_state.json
```

并从最近的 step checkpoint 继续。若训练段已完成但验证中断，会根据 `status.json`
继续该 checkpoint 的验证，不重复训练。续训在采样器层跳过已消费批次，不重新解码这些帧。

## 达标和停止

W1 达标使用固定测试配置中的四项条件：

1. 干净 p1/p2/p3 平均至少改善 10%；
2. sigma=0.05 平均退化不超过 2%；
3. known-noise DA 平均改善至少 2%；
4. DA 在 p1 和 p3 上分别改善。

通过后，`controller_state.json` 中记录：

```text
state: complete
reason: full_w1_passed
selected_checkpoint: ...
```

未通过时，以下任一条件会停止当前分支：

- 6k step 仍无 fast 合格 checkpoint；
- 4k step 后稳健 checkpoint 连续三次没有至少 0.5% 的新改善；
- 连续两次高噪声退化超过 8%；
- 12k step 仍未通过完整测试。

W16 代码不在此版本中修改。只有 W1 产生 `selected_checkpoint` 后，再根据 W1 的实际结果决定 W16 初始化和训练设置。
